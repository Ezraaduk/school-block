🔒 Blocage d'Internet – Activation du Mode Avion Obligatoire
Dans le cadre du mode sécurisé, l’application applique un blocage d’Internet basé sur une vérification périodique de la connexion. Ce mécanisme est conçu pour empêcher toute navigation en ligne, accès aux ressources distantes, ou toute tentative de triche durant une session de travail encadrée.

🛑 Comment fonctionne le blocage :
Toutes les 5 secondes, l’application tente de se connecter à plusieurs serveurs connus (tels que 1.1.1.1, 8.8.8.8, ou www.bing.com). Si une connexion réussit, cela signifie que l’accès Internet est toujours actif.

Dans ce cas :
- L'ordinateur est bloquer, affichant un message d'erreur, un professeur devra intervenir pour débloquer l'ordinateur. (Réactiver le mode avion avant d'inserer votre clé USB.)

✈️ Activer le mode avion :
L’activation du mode avion est donc nécessaire pour désactiver toutes les connexions réseau (Wi-Fi, Ethernet ou données mobiles). Sans cette action, le mode examen ne sera pas considéré comme pleinement opérationnel.

⚠️ Important :
Le blocage d’Internet repose sur une vérification active : si Internet est réactivé manuellement, l’application le détectera dans les 5 secondes suivantes et l'ordinateur sera à nouveau bloquer.

Comme pour le blocage du presse-papier, un professeur doit activer manuellement le mode avion : le logiciel ne peut pas désactiver Internet à sa place pour des raisons de sécurité et de restrictions système.

🔐 Objectif :
Ce système renforce la sécurité numérique en empêchant toute consultation extérieure pendant une activité contrôlée (examen, devoir surveillé, etc.), en complément des autres mesures comme :

- Le blocage des applications non autorisées.
- Le blocage du presse-papier pour interdire le copier-coller.
- La gestion par clé USB administrateur.
